## 四、三大综艺站：沙滩 + 花园迷宫 + 撕名牌

### 4.1 综艺感（韩国综艺风格）
参考《Running Man》《新西游记》《出差15夜》的后期手法，克制使用网络用语：

- **综艺字幕条**：照片卡片/回声区顶部出现韩式字幕条（白底黑框/黑底白字，短句，如“名场面来了”“全员高能”“稳稳拿捏”“就这？”）。
- **反应表情/徽章**：每站一个“反应 tag”（🔥😱 等少量 emoji 徽章，仅装饰）。
- **回合制信息结构**：三大站展示为“第 N 回 · 高能片段”，照片按回放/片段分组。
- **综艺标题**沿用新命名风格。
- 语言规则：网络用语每站 ≤ 1 处、只作标题/字幕点缀，正文反馈不改写。

### 4.2 更多照片 + 照片↔反馈一一对应
- 三大站**精选照片数量增加**（沙滩 ~10、迷宫 ~10、撕名牌 ~10；其余站保持 4 张）。
- 每张精选照片绑定**一条对应反馈**（“照片 + 反馈”一体卡片，不再评论与照片分离）：

```text
  [照片]  ← 卡片主体
  ─────────────
  “现场拆解版反馈句”   ← 字幕风格，事实来自反馈原文
```

- 数据：新建 `scenes[].photoFeedback`（photoIndex → 反馈条目），在 `scene-details.js` 或新文件维护；内容从反馈文档提炼，做综艺化语气但**不改变事实**。
- 照片来源与精选原则：沿用 `allImages`（沙滩 43、迷宫 37、撕名牌 33），在“差异性 + 代表性 + 反馈匹配”基础上选 10 张。
- 点击照片仍可进入该站完整相册；有反馈卡片的照片带角标。

## 五、爬山：点击逐步出片 + 堆叠

### 交互
- 汉拿山站照片区初始为空或只显示触发提示（如登山杖/脚印动画 + “点击一步步上山”）。
- **点击屏幕（站内任意点击）→ 浮现两张照片** → 再点击 → 再浮现两张 → 依此循环。
- 照片以**登山式堆叠**呈现：新出现的照片叠在旧照片上方/后方，带轻微旋转与错位，形成“越登越高”的堆叠；到达山顶后出现山顶旗与完成提示。
- 提供“摊开相册”入口：把堆叠打散成完整相册/恢复平铺。
- 移动端：点击也可用（tap）；减少动效时直接平铺全部。

### 需要确认
- 触发方式：A 点击屏幕任意处 / B 点击站内“登山”按钮。默认 **A（全站点击）**，用一次性提示引导。

## 六、真心话时刻：信件 → 锦秋邮箱 → 展开留言

### 模块改名
- 反馈互动整体更名为 **“真心话时刻”**（取代“留句话/评论”入口字样；评论可保留为“真心话小纸条”）。

### 流程
1. 用户在任一站点点击“真心话时刻” → 提交一句话（称呼 + 内容）。
2. 提交后生成一封**小信件**（信封样式：折角、火漆/邮票样装饰）。
3. 信件**动画投递**到页面末尾的**锦秋邮箱**：
   - 页尾新增邮箱场景（带锦秋 Logo 的邮箱/邮筒）。“投递”：信件从弹出位置飞向邮箱，滚动自动跟随到页尾，落进邮箱、邮箱轻晃。
4. 邮箱**慢慢展开**：信封口打开 → 陆续“吐出”/罗列**全部留言**（含此前历史留言；新留言置顶并高亮）。
5. 留言仍存本机 localStorage（沿用 `activity-comments.v1`；评论与信件合并或分开，默认合并展示在邮箱里）。

### 交互细节
- 投递动画用 fixed 元素 + transform 过渡（CSS/JS），约 1.2s，可被打断/跳过（点邮箱直接看留言）。
- 减少动效：跳过飞行，直接滚动到邮箱。
- 邮箱场景放于“给下一次的建议”回声区之后、页尾旗帜前。
