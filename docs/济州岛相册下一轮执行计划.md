## 一、首页：济州岛完整轮廓 + 场景过渡

### 目标
打开页面第一眼确定“这是济州岛”，并从首页自然过渡到第一站内容。

### 首页布局（纵向一屏）

```text
       （济州岛轮廓背景，居中、低饱和青绿）

                  锦秋 Logo

                  沿着活动走
                    WIN BIG
```

### 轮廓实现
- 使用**可核验的济州岛简化轮廓**：优先从公开 GeoJSON / 地图数据提取边界，生成单色描边的“岛屿印章”SVG（东西长、南北窄的椭圆岛形）。
- 若数据获取失败，退化为手绘近似轮廓，并标注“装饰性轮廓，非精确地图”。
- 岛屿内加极简低对比装饰：少量橘子点、海鸥、石墙短线。

### 过渡方法（重点）
“岛屿 → 道路”的生长过渡：

1. 顶部 100svh 为“岛屿站”：Logo、标题居中，岛屿轮廓作背景印章。
2. 向下滚动（滚动驱动动画 / IntersectionObserver）：
   - 岛屿轮廓**淡出 + 轻微下沉缩放**。
   - 中央出现并**拉长一条道路**（复用 `road-surface` / 中心线样式），把视线引向第一站。
3. 进入第一站照片展位。
4. 减少动效模式：直接淡入淡出，无位移缩放。

### 边界
- 动效只用 CSS / 原生 JS，不引入 WebGL。
- 手机端岛屿缩小、细节减少，标题可读。

## 五、每条回答增加“点赞 + 评论”

### 交互
- 卡片右下角出现 **点赞** 与 **评论** 入口，视觉像网页评论工具条。
- **点赞**：点击切换赞/取消，显示当前赞数；`aria-pressed` 表示状态。
- **评论**：点击后卡片下方展开小评论框；输入称呼（沿用本机身份）+ 一句评论，提交后以气泡挂在卡片下；可删除自己的评论，显示时间。
- 条目 ID：`stationId + 下标`（如 `tag-road-0`）。

### 数据与存储
- 新 localStorage 键：`jinqiu.jeju.reactions.v1`。
- 结构：

```text
{
  version: 1,
  reactions: {
    "tag-road-0": { likes: 0, likedByMe: false, notes: [{ id, name, text, createdAt }] },
    ...
  }
}
```

- 与 `jinqiu.jeju.activity-comments.v1` 互不干扰；沿用现有校验、上限、异常回退写法。

## 六、交互与丝滑设计（本节新增）

### 6.1 首页视差与进入动画
- **鼠标视差**：桌面端鼠标轻微移动时，岛屿印章与 Logo 以极低幅度相对错位（0.5s 缓动跟随），背光装饰略有远近感。
- **进入过渡**：向下滚动时岛屿淡出下沉、道路拉长浮现（见第一节），中间穿插一次柔和的名牌/标题游移。
- 触屏无鼠标视差；减少动效时全部关闭。

### 6.2 内容揭示（scroll reveal）
- 每站进入视口时内容**分层上浮**：
  1. 标题与花字先出现；
  2. 照片展位、路牌、配件随后；
  3. 回声卡片**逐张交错上浮**（间隔约 60ms）。
- 用 IntersectionObserver + CSS transition 实现，只触发一次；减少动效直接显示。

### 6.3 道路生长与景深跟随
- 滚动时道路与中心线呈**生长式**衔接（scaleY / 描画动画），与前文“岛屿→道路”统一为同一种语言。
- 照片在滚动过程中保持轻微景深位移（沿用现有 3D 透视），不做自动旋转或镜头摇晃。

### 6.4 微交互（hover / active）
- 照片 hover：轻微抬升 + 阴影加深；点击时有短暂“按入”反馈（scale 0.99，150ms）。
- 路牌（정지 / 메모 等）hover：轻微摆动（rotate ±2deg）提示可点击。
- 点赞：点击后单次弹性缩放（CSS keyframes，不循环）。
- 评论气泡：滑入展开。

### 6.5 滚动节奏（可选，默认关闭）
- 站点圆点指示器（不显示文字）：跟随滚动高亮，点击平滑滚动到对应站。
- **默认不启用**——上一轮明确去掉了导航与操作提示；若你点头再加入，且保持极简、无文字。

### 实现与回退约束
- 全部用 CSS 3D / 原生 JS 过渡与 IntersectionObserver；不引入动画库或 WebGL。
- 每项动效都带 `prefers-reduced-motion` 回退（直接显示/淡入）。
- 不遮挡内容、不拦截点击、不持续循环动画；低端机上动效数量自动减半（`(pointer:coarse)` 或视口过小时只保留揭示动画）。
