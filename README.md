# WIN BIG · 济州岛记忆步道原型

## 本机预览

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://localhost:4173/ 。

## 当前结构

1. 页面最前是自动播放的纪念视频；视频结束后自动播放主题曲 **The Script - Hall of Fame**。随后进入开场页，居中展示锦秋 Logo、主题句 **“这一次，我们赢个大的 / Win Big, Make Waves.”** 与 **WIN BIG**；背景为济州岛轮廓印章，岛上配有汉拿山小火山（`한라산`）、橘子与海鸥点缀。
2. 汉拿山站现在位于视频与会议站之间；六个主路场景连续铺开，每站右侧是**微缩图墙**（该站全部照片缩略图，鼠标悬停原处放大、点击进入相册），不再显示副标题/描述文字。
3. 每站有不同济州风味装饰与韩语小标签（纯娱乐，如 `환영해요`、`건배`、`한라산`）。
4. 标题综艺化：内部会议 → **JQer在济州岛的48小时**；吃吃喝喝 → **锦秋小饭桌-内部版**。
5. 三大综艺站（沙滩运动 / 花园迷宫 / 撕名牌大战）各展示 10 张精选照片，**每张照片绑定一句对应反馈**（照片 + 现场点评一体卡片，昵称式字幕 + 回合标题如“第 1 回 · 全员高能”），不再把评论与照片分开；有对应头像的反馈人会显示真实头像。
6. 汉拿山站改成**从中间向左右两侧铺开**：中间是「点击任意处，让照片从卡片左右两边铺开」的面板（含铺开按钮、进度条、真心话入口），每点一次，左右各两张、共 4 张照片从卡片背后向两侧飞出；铺开的是挑好的 **8 张精选**，两次点完，全程在一屏之内、中间卡片全程不动。其余照片可从单张放大后左右翻看，也在页尾「打开完整相册」里；系统减少动态效果时自动关闭飞入动画。
7. 互动更名为**真心话时刻**：提交留言后生成一张小纸条，飞进页尾**贴有锦秋 Logo 的漂流瓶**；瓶身轻轻漂浮，留言与评论在下方展开（新留言高亮）。
8. 从照片合集点击任意照片，可进入单张大图查看；支持上一张/下一张、键盘左右键，以及“退出当前照片”返回合集。
9. 全页使用轻量 CSS 3D 与原生 JS：内容滚动揭示、微缩图 hover 放大、照片 hover/点击反馈、路牌轻摆、点赞弹跳、首页视差与岛屿过渡；`prefers-reduced-motion` 全部回退为静态可见。
10. 配色为**旧纸/相纸质感**：米白纸底、墨褐文字、赭橘强调，全局轻微纸纹噪点，去除系统蓝/青模板色调；漂流瓶、留言与卡片均保持暖纸色。

## 文件

- `index.html` / `styles.css` / `script.js`：记忆步道、综艺站、真心话漂流瓶与完整相册入口。
- `activity-data.js`：11 个原活动分类、183 张图片、六个主路场景精选分组（含扩充后的综艺站 10 张及汉拿山完整照片墙数据）。
- `scene-details.js`：六站标题花字、韩语标签、小配件、按环节提炼反馈（`highlights`）、综艺照片×反馈卡（`variety`）、汉拿山全宽照片墙标记（`fullWidthGallery`）及结尾建议（`feedbackSuggestions`）。
- `feedback-data.js`：反馈原文快照（不再被页面引用，仅留档）。
- `锦秋团建照片/`：网页使用的 183 张本地原始图片，未修改并随项目提交。
- `锦秋基金活动相册/`：4.5GB 原始素材归档，仅保留在本机，按要求不上传 GitHub。
- `public/brand/jinqiu-logo.png`：锦秋 Logo 原图，未重绘。
- `public/avatars/`：用户提供的反馈人头像裁切图（含仲昭阳、郑晓超、石头、马梦真、张旭、周琪、诺诺与乔众龙）。
- `public/fonts/lato-*.woff2`：本地 Lato 字体文件。
- `docs/`：执行方案与综艺化升级计划文档。
- `editorial.html` / `voyage-five-days.html`：此前版本，保留用于比较。

## 事实边界

- 活动分区依据 Lark 文档《美好的记忆-202609｜济州岛》的标题结构；页面只使用实际存在的本地图片。
- 反馈内容来自《2026H2济州岛团建活动反馈收集》，页面展示为按环节提炼的回答（“主角 + 原话”）；综艺站的“现场点评”改编自同一文档，只做语气综艺化，不改事实。
- 首页金句来自《It's Time to Win Big｜锦秋基金的下一次创业》原文。
- 装饰中的韩语与济州元素（火山、橘子、玄武岩、石墙、烤肉海鲜、综艺字幕）仅用于视觉与娱乐表达，不构成对实际行程地点的断言。
- 留言、点赞、评论使用浏览器 `localStorage`（键 `jinqiu.jeju.activity-comments.v1` 与 `jinqiu.jeju.reactions.v1`），不会自动同步给其他同事。若要多人共享，需要接入内部身份与后端存储。
