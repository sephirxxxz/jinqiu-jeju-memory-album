# WIN BIG · 济州岛记忆步道原型

## 本机预览

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://localhost:4173/ 。

## 当前结构

页面从上到下只有三段：**开场视频页 → 六个活动站 → 信箱页 → 页脚**。

1. 开场是自动播放的纪念视频；视频结束后自动播放主题曲 **The Script - Hall of Fame**。页面上只保留标题「这一次，我们赢个大的」和左上角锦秋 Logo。
2. 六个活动站按顺序铺开：**WIN BIG · 一起聊聊我们的方向 → 沙滩运动与团队挑战 → 花园迷宫 → 汉拿山我们来了 → 撕名牌大战 → JQer自己的小饭桌**。每站左侧是活动名，右侧是**微缩图墙**（该站全部照片缩略图，超出 12 张时用「+N」进相册），路面上放四张精选照片。
3. 每站下方是留言反馈区，标题按活动各写一句：聊完之后，大家有了这些想法 / 原来你还有这一面 / 一起找路，一起想办法 / 爬完这座山，想说点什么 / 玩的时候，大家都认真了 / 饭桌上，聊得更近了。
4. 三大活动站（沙滩运动 / 花园迷宫 / 撕名牌大战）各展示 10 张精选照片，**每张照片绑定一句对应反馈**（照片 + 现场点评一体卡片，昵称式字幕 + 回合标题如“第 1 回 · 全员高能”）；有对应头像的反馈人会显示真实头像。
5. 汉拿山站和其他站完全同一种展示方式：四张精选在路上，其余从微缩图墙或单张放大翻看。此前那套「从卡片向两侧铺开」的交互已整体删除。
6. 页尾是**信箱页**：图标用 `public/brand/postbox.svg`（fluent-emoji-flat 的 postbox，按反馈**不放锦秋 Logo**），留言按活动分组列在下方，新留言高亮。
7. 从照片合集点击任意照片，可进入单张大图查看；支持上一张/下一张、键盘左右键，以及“退出当前照片”返回合集。
8. **全站不留装饰性小字**：不再有英文踢脚线、章节说明句、韩语小标签、编号和“仅供参考”类注脚。保留的是活动名、真实反馈原文、姓名、按钮和计数。唯一保留的说明是留言框旁的一行「留言只保存在这台电脑上，其他同事看不到。」，用正常字号写在提交按钮下方。
9. 全页使用轻量 CSS 3D 与原生 JS：内容滚动揭示、微缩图 hover 放大、照片 hover/点击反馈、路牌轻摆、点赞弹跳；`prefers-reduced-motion` 全部回退为静态可见。
10. 配色为**旧纸/相纸质感**：米白纸底、墨褐文字、赭橘强调，全局轻微纸纹噪点。

## 文件

- `index.html` / `styles.css` / `script.js`：开场视频、六站步道、信箱页与相册 / 留言弹窗。
- `activity-data.js`：11 个原活动分类、183 张图片、六个主路场景及其顺序。
- `scene-details.js`：六站的标题花字、小配件、按环节提炼反馈（`highlights`）、照片×反馈卡（`variety`）、每站留言区标题（`echoTitle`）及结尾建议（`feedbackSuggestions`）。
- `feedback-data.js`：反馈原文快照（不再被页面引用，仅留档）。
- `锦秋团建照片/`：网页使用的 183 张本地原始图片，未修改并随项目提交。
- `锦秋基金活动相册/`：4.5GB 原始素材归档，仅保留在本机，按要求不上传 GitHub。
- `public/brand/jinqiu-logo.png`：锦秋 Logo 原图，未重绘。
- `public/brand/postbox.svg`：页尾信箱图标。
- `public/brand/jeju-island.svg`：济州岛轮廓图形（当前未被页面引用，保留备用）。
- `public/avatars/`：用户提供的反馈人头像裁切图（含仲昭阳、郑晓超、石头、马梦真、张旭、周琪、诺诺与乔众龙）。
- `public/fonts/lato-*.woff2`：本地 Lato 字体文件。
- `docs/`：执行方案与升级计划文档。
- `editorial.*` / `voyage-five-days.*`：此前版本，**已不被 `index.html` 引用**，保留用于比较。

## 事实边界

- 活动分区依据 Lark 文档《美好的记忆-202609｜济州岛》的标题结构；页面只使用实际存在的本地图片。
- 反馈内容来自《2026H2济州岛团建活动反馈收集》，页面展示为按环节提炼的回答（“主角 + 原话”）；综艺站的“现场点评”改编自同一文档，只做语气综艺化，不改事实。
- 首页金句来自《It's Time to Win Big｜锦秋基金的下一次创业》原文。
- 装饰中的济州元素（火山、橘子、玄武岩、石墙、烤肉海鲜）仅用于视觉与娱乐表达，不构成对实际行程地点的断言。
- 留言、点赞、评论使用浏览器 `localStorage`（键 `jinqiu.jeju.activity-comments.v1` 与 `jinqiu.jeju.reactions.v1`），不会自动同步给其他同事。若要多人共享，需要接入内部身份与后端存储。
